JAVED PRESS WORDPRESS THEME

Install
1. In WordPress, open Appearance > Themes > Add New > Upload Theme.
2. Upload javedpress.zip and activate it.
3. Open Appearance > Customize > Javed Press Details to edit address, hours, email, or creator credit.
4. Make sure Settings > Reading uses the site homepage. The theme creates About Us, Services, and Contact pages when activated.

The theme includes the current Javed Press app, responsive layout, animations, chatbot, microphone input, videos, services, map and contact form. It does not require a page builder plugin.
